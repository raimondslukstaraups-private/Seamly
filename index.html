    2. Tile & spacing

    The tile is the unit that repeats. Normally motifs that cross an edge come back in on the opposite side. Keep them inside when each tile is printed on its own. In a brick grid, motifs that would be cut are left out.

    3. Layout

    Seamly template: positions, sizes and angles are read exactly, so no detection is needed.

    Biggest spots get the biggest motifs. Use motif weights to change how many spots each one gets. With "Same colour = same motif", each colour group gets one motif. Untick motifs you don't want, or untick this option to mix every motif in.
